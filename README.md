# 🩸 Blood Donor App

Find blood donors by blood group & location and request blood instantly.

## 🚀 Features
- Search Donors by Blood Group
- Search by Location / City
- Donor Registration
- Blood Request System
- Admin Dashboard

## 🛠️ Tech Stack
- Python
- Flask
- SQLite / MySQL
- HTML / CSS / JavaScript
- Bootstrap

## 📦 How to Run
```bash
pip install -r requirements.txt
python app.py
